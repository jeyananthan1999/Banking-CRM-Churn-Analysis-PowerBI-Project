# 📊 Bank CRM Analytics Dashboard | Excel, Power BI

## 📌 Project Overview
This project focuses on analyzing customer behavior and identifying key drivers of **customer churn** in a Bank CRM system.

The objective was to generate data-driven insights to improve **customer retention, engagement, and overall business performance**.



## 📁 Dataset Details
- Dataset contains ~10,000 customer records
- Includes demographics, account balance, product usage, credit card status, activity, and churn information
- Multiple relational tables integrated into a **master dataset using Excel Power Query**



## 🛠 Approach
- Data cleaning and transformation using **Excel Power Query**
- Build interactive dashboards in **Power BI** to analyze churn patterns and customer behavior using DAX for Measures and Calculated Columns


## 📊 KPIs & Metrics

- Total Customers  
- Active vs Inactive Customers  
- Churned Customers  
- Churn Rate (%)  
- Average Balance  
- Revenue & Conversion Metrics  


## 🔎 Key Insights

- Customers with **1 product show highest churn (27.71%)**, while churn drops for **2 products (7.58%)**
- **Inactive customers have higher churn (26.85%)** compared to active customers (14.27%)
- **Germany shows highest churn rate (32.44%)**
- Customers aged **50+ have highest churn (44.65%)**
- Identified **59.45% drop-off rate**, highlighting significant retention challenges
- Churn does not follow a consistent trend across tenure → indicates multiple influencing factors



## 📈 Dashboard Features

- KPI cards for revenue, churn rate, and customer metrics  
- Customer segmentation analysis  
- Churn trend visualization  
- Region-wise and demographic performance analysis  
- Interactive filters for dynamic insights  



## 🛠 Tools & Technologies Used

- Power BI (Dashboard Development)
- Excel (Power Query, Data Cleaning)
- DAX (KPI Calculations, Measures, Calculated Columns)


## 💡 Business Impact

- Identified **high-risk customer segments**
- Highlighted importance of **customer activity in reducing churn**
- Provided insights for **targeted retention strategies**
- Enabled **data-driven decision making** for CRM optimization
